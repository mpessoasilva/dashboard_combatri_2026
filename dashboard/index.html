Como foi feita a análise

Os passos seguidos, do arquivo original ao dashboard. A descrição completa está no README do repositório.

  1. Catalogação

    A lista de trabalhos e sessões (CSV) foi casada com os arquivos baixados pelo título. Cópias idênticas foram removidas, restando 44 trabalhos únicos.

  2. Extração do texto

    PDFs foram convertidos com pdftotext; DOCX foram lidos do XML do arquivo; DOC foi lido por um leitor próprio, porque o LibreOffice não abriu esses arquivos.

  3. Leitura e registro

    Para cada trabalho, o resumo e a conclusão foram lidos e os campos objetivo, técnica, dados, resultados e conclusões foram registrados. Dados que o trabalho não informa são indicados como tal.

  4. Temas

    Os trabalhos foram agrupados em 8 temas a partir dos resumos. Cada trabalho pertence a um único tema. A divisão é uma leitura, não o resultado de um algoritmo de agrupamento.

  5. Dashboard e downloads

    Os arquivos originais e a classificação (CSV e JSON) foram organizados para download, e os dados foram publicados nesta página.

  6. Verificação

    Conferimos as contagens e a renderização da página. Filtros e busca não foram testados em navegador real.

Os textos de análise foram extraídos dos arquivos originais publicados no encontro. Cada trabalho pode ser baixado no arquivo original.
